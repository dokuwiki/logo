# Fonts

`LiberationSans-Bold.ttf` is version 2.1.5, copied here unchanged so the build
draws the same word mark on any machine. It carries Arial's metrics, which is
what the logo's lettering was drawn from.

It is licensed under the SIL Open Font License 1.1, in `LICENSE`. That licence
reserves the name Liberation: a changed copy of this file, a subset among them,
may not keep the name. Replace the file wholesale rather than editing it.
