Each row draws the one file at one size, three times over, once per mechanism that can reach into it. They should look the same. Where they do not, that mechanism is not working.

img loads the file as its own document, so its media queries measure the drawing. inline, container pastes the markup into this page, where a media query would measure the window instead and only a container query measures the drawing. inline, class pastes it in and sets the level's class, which is what a host does when nothing can measure for it. Beside each band the same class is drawn large, once, because a shape cannot be judged at the size it is meant for.
