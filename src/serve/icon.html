The icon

The DokuWiki icon tries to follow the Material Design system icon guidelines, but takes some liberties by expanding slightly past the 20dp live area, into the surrounding margin.

The icon uses a single fillable path element and can easily be coloured by CSS when used inline. An outlined and a filled version are provided.
