# DokuWiki Logo

This is a modern redesign of the classic DokuWiki logo originally created by Esther Brunner.

The repository holds three designs: the logo, a Material Design icon for the places a logo does
not belong, and the logo as line art in one colour, for print.

## Build

All three designs are generated by one build script, not in a graphics editor. The script reads the
basic design parameters from `src/logo/logo.yaml`, `src/icon/icon.yaml` and `src/logo/line.yaml`.
Simple tweaks can be made there. Larger changes require editing the part sources beside each design
file.

```
npm install
npm run build
```

That writes every file in `dist/`, all of which are checked in, so a change to
the design shows up as a change to them.

## Look at it

See https://dokuwiki.github.io/logo/

On a local checkout, use:

```
npm run serve
```
