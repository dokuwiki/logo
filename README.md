# DokuWiki Logo

This is a modern redesign of the classic DokuWiki logo originally created by Esther Brunner.

## Build

The logo files are generated by a build script, not in a graphics editor. The script reads the
basic design parameters from `src/logo.yaml`. Simple tweaks can be made there. Larger changes
require editing the `src/parts/` sources.

```
npm install
npm run build
```

That writes every file in `dist/`, all of which are checked in, so a change to
the design shows up as a change to them.

## Look at it

```
npm run serve
```
